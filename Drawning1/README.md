# Комплект КМД: сборка из одного источника

## Запуск

    python3 build.py

Ненулевой код возврата, если хоть один DXF не прошёл аудит.

## Структура

    parts.yaml            единый источник данных изделия
    build.py              расчёт -> сверка -> генерация -> аудит
    gostcad/
      style.py            слои, стиль GOST_A, размерные стили GOST_2307/R/LEADER
      draw.py             текст, dim_h/dim_v/dim_r, полки-выноски
      table.py            табличный движок: объединённые и дробные ячейки
      calc.py             развёртки и массы (единственное место расчёта)
      validate.py         блокирующий аудит DXF
    generators/
      plate.py            полоса с отверстиями
      embed.py            закладная деталь в двух видах
      hook.py             подвеска с тремя гибами 180 град.
      tables.py           ведомость деталей и обе спецификации
    out/                  результат

## Что проверяет аудит

* целостность по ezdxf.audit;
* дубликаты сегментов;
* коллинеарные наложения, с разворачиванием анонимных блоков размеров
  и выносок (иначе наложение выносной на осевую не видно);
* NaN/Inf в координатах;
* совпадение DIMENSION.get_measurement() с проектными значениями;
* вылезание текста за границы граф таблиц.

## Найденные грабли ezdxf (закреплены в коде)

* радиусный размер не рисует выноску к вынесенному тексту без
  `dimtmove=1` и `dimupt=1` в размерном стиле;
* `dimtofl=1` добавляет лишнюю линию от центра к дуге - для ГОСТ не нужна;
* выносные линии надо подавлять (`dimse1`/`dimse2`) везде, где их роль
  выполняет осевая линия или выносная соседнего размера в цепи.

## Допуски сверки

    TOL_MASS = 0.02 кг      TOL_LEN = 2 мм

Расхождения печатаются отдельным блоком и не блокируют сборку:
бумажная спецификация может быть округлена, решение остаётся за инженером.

## Интерфейс

    pip install ruamel.yaml
    python3 ui.py

Поднимает локальный сервер на 127.0.0.1:8765 и открывает браузер.
Наружу ничего не слушает.

Слева - форма параметров, она строится из parts.yaml автоматически:
добавили поле в данные - оно появилось в интерфейсе. Контрольные значения
из бумажной спецификации (mass_ref, length_ref) не редактируются, чтобы
сверка оставалась честной.

Справа - отчёт сборки и превью всех DXF. Клик по превью - крупно,
рядом ссылка на скачивание файла.

Кнопки:
  Сохранить параметры  - записывает форму в parts.yaml (комментарии
                         в файле сохраняются, правится только значение)
  Собрать              - сохраняет и запускает build.py, показывает
                         таблицу сверки, отчёт аудита и обновлённые превью

Проверка интерфейса целиком:

    python3 test_ui.py

Поднимает сервер в потоке, правит параметр, собирает комплект, проверяет
превью и скачивание, затем возвращает parts.yaml в исходное состояние.
