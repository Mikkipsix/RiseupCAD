# КМД: сборка комплекта и распознавание чертежей

Две задачи в одном интерфейсе:

1. **Сборка комплекта** — чертежи и спецификации генерируются из одного
   файла данных `parts.yaml`. Развёртки и массы вычисляются, а не
   переписываются руками. Каждый DXF проходит обязательный аудит.
2. **Распознавание** — растровый чертёж (PNG, JPG, TIFF, PDF) разбирается
   на отрезки, окружности и числа, подбирается масштаб, выдаётся DXF в
   миллиметрах.

## Установка

    Windows:       install.bat
    Linux / macOS: ./install.sh

Или вручную: `pip install -r requirements.txt`

Для чтения чисел с чертежа нужен движок **tesseract** (отдельная программа,
не пакет Python):

    Ubuntu/Debian  sudo apt install tesseract-ocr
    macOS          brew install tesseract
    Windows        сборка UB Mannheim, затем добавить в PATH

Без него распознаётся геометрия, а масштаб задаётся вручную.

## Запуск

    python ui.py

Откроется браузер на `http://127.0.0.1:8765`. Сервер слушает только
локальный адрес и наружу ничего не отправляет.

Вкладка **Окружение** показывает, что установлено, а что нет, и какой
командой доставить недостающее. Если интерфейс ведёт себя странно —
начинать надо оттуда.

## Вкладка «Сборка комплекта»

Слева форма параметров, она строится из `parts.yaml` автоматически:
добавили поле в данные — оно появилось в интерфейсе. Контрольные значения
из бумажной спецификации (`mass_ref`, `length_ref`) не редактируются, чтобы
сверка оставалась честной.

«Собрать» запускает расчёт, сверку, генерацию и аудит. Справа появляется
отчёт и превью всех DXF; клик по превью — крупно, рядом ссылка на скачивание.

Правка `parts.yaml` сохраняет комментарии (через ruamel.yaml) и делает
резервную копию `parts.yaml.bak`. Без ruamel файл тоже сохранится, но
комментарии потеряются — интерфейс об этом предупредит.

## Вкладка «Распознавание чертежа»

Перетащите файл, нажмите «Распознать». Справа — контрольная картинка:
синим показаны найденные отрезки, зелёным окружности, оранжевым числа,
попавшие в калибровку, фиолетовым — остальные.

**Как подбирается масштаб.** Размер — это расстояние между двумя выносными
линиями, между которыми стоит число. У всех настоящих размеров отношение
«значение / это расстояние» одинаковое, поэтому берётся самый населённый
кластер таких отношений. В отчёте печатается сверка с невязками по каждому
размеру — видно, на чём именно построен масштаб и что не вошло.

Если автоподбор ошибся, выберите заведомо верный размер из списка или
впишите мм/пиксель вручную и нажмите «Распознать» ещё раз — файл
пересоберётся без повторной загрузки.

**Честно о точности.** На сканах и фотографиях от руки распознавание даёт
геометрию с погрешностью порядка процентов, а OCR читает не все числа
(вертикальные надписи, дроби, символы диаметра). Это заготовка для
доработки в CAD, а не готовая деталировка. Смысл инструмента — снять
ручной обмер и обводку, а не заменить инженера.

## Проверка

    python build.py      сборка комплекта, ненулевой код при провале аудита
    python test_ui.py    сквозная проверка интерфейса
    python test_ui.py путь/к/чертежу.png     плюс проверка распознавания

## Структура

    parts.yaml          единый источник данных изделия
    build.py            расчёт -> сверка -> генерация -> аудит
    ui.py               локальный интерфейс
    gostcad/
      style.py          слои, стиль GOST_A, размерные стили
      draw.py           текст, размеры, полки-выноски
      table.py          таблицы: объединённые и дробные ячейки
      calc.py           развёртки и массы
      validate.py       блокирующий аудит DXF
    generators/         полоса, закладная деталь, подвеска, таблицы
    vector/raster.py    распознавание растра
    out/                результат сборки

## Что проверяет аудит

* целостность по ezdxf.audit;
* дубликаты сегментов;
* коллинеарные наложения, с разворачиванием анонимных блоков размеров
  и выносок — иначе наложение выносной на осевую не видно;
* NaN/Inf в координатах;
* совпадение DIMENSION.get_measurement() с проектными значениями;
* вылезание текста за границы граф таблиц.

## Грабли, закреплённые в коде

* ezdxf не рисует выноску к вынесенному радиусному размеру без
  `dimtmove=1` и `dimupt=1` в размерном стиле;
* `dimtofl=1` добавляет лишнюю линию от центра к дуге — по ГОСТ не нужна;
* выносные линии надо подавлять (`dimse1`/`dimse2`) везде, где их роль
  выполняет осевая или выносная соседнего размера в цепи;
* в Python `isinstance(True, int)` истинно — булевы поля надо проверять
  до числовых, иначе форма ломается на них;
* вертикальные размерные надписи по ГОСТ 2.307 читаются снизу вверх,
  поэтому для OCR страницу надо поворачивать **по часовой стрелке**.


## Как устроено распознавание

Конвейер в `vector/`, шесть шагов. Каждый шаг решает одну задачу и
отдаёт результат следующему.

    page.py       загрузка растра или страницы PDF, выравнивание фона
                  делением на размытую копию, устранение перекоса
    detect.py     отрезки (Хаф + слияние), измерение толщины штриха и
                  доли заливки, поиск отверстий по центровым крестам,
                  поиск дуг по локальной кривизне контура туши
    solve.py      OCR чисел, привязка чисел к выносным линиям,
                  подбор масштаба, решение координат МНК
    assemble.py   замыкание контуров обходом граней графа, сборка
                  модели, вывод DXF
    pipeline.py   оркестрация, отчёт, контрольная картинка

### Три решения, которые дали качество

**Размер - это ограничение, а не подпись.** Если на чертеже стоит 150, то
расстояние между соответствующими выносными обязано быть ровно 150.
Координаты всех линий группируются в кластеры, кластеры решаются методом
наименьших квадратов при ограничениях от размеров. Поэтому в готовом DXF
контур выходит ровно 150.0 x 50.0, а не 149.3 x 50.4.

**Отверстия ищутся по центровым крестам.** По ГОСТ 2.307 центр отверстия
обозначается пересечением центровых линий. Голый HoughCircles на чертеже
даёт десятки ложных срабатываний: буквы «О», «Ф», цифра «8», пересечения
линий. Поиск идёт от крестов, а решает радиальный профиль: у отверстия он
даёт пик (тушь нарастает к кольцу и резко пропадает снаружи), у
пересечения линий монотонно спадает от центра.

**Дуги ищутся по кривизне границы туши.** Вычитать прямые из растра и
искать дуги в остатке бесполезно: Хаф забирает пологие части дуги себе, и
она рассыпается на огрызки. Поэтому в каждой точке контура по трём
отсчётам строится окружность, участки с устойчивым радиусом объединяются
и подгоняются МНК. Почти полные окружности отбрасываются - это буквы «О»,
«0» и «8», а настоящие отверстия ищутся отдельно.

**Прямые и дуги сводятся в точку касания.** Хаф обрывает прямую, не
доводя до касания, а дуга наоборот заезжает за него. Ни подтягивание
прямой к концу дуги, ни обратное по отдельности не работают: точка
касания считается геометрически, как основание перпендикуляра из центра
дуги на прямую, и туда сводятся оба конца. После этого скругление
становится сегментом полилинии с выпуклостью, а не отдельным объектом.

**Контур определяется структурно.** На ксерокопии основная линия и
размерная бывают одной толщины, поэтому делить только по весу штриха
нельзя. Контур - это то, что замкнуто. Отрезки разбиваются в Т-образных
примыканиях, строится планарный граф, обходятся грани. Грани, собранные
преимущественно из размерных и выносных линий, отбрасываются.

### Проверка на реальных чертежах

    python test_recognition.py

Сравнивает результат с чертежами, построенными вручную по тем же
исходникам. Проверяются инженерные величины, а не похожесть картинки.

| Исходник | Контур | Отверстия | Размеры |
|---|---|---|---|
| поз.14, полоса | 150.0 x 50.0 замкнут | ⌀10 в (100.0, 25.0) | 150, 50, 50 - все |
| ЗД1, закладная | 50.0 x 300.0 замкнут | ⌀8 в (25.0, 280.0) и (25.0, 20.0) | 20, 25, 50, 260, 300 из шести |
| поз.3, подвеска | дуги гибов R32.1 и R46.7 | нет | 490 |

Отдельно проверяется сшивка прямых и дуг в замкнутую полилинию:

    python test_arcs.py

Масштаб, подобранный автоматически, против ручного обмера:
0.8842 против 0.877 мм/px на ЗД1 и 1.3179 против 1.324 на поз.3.

### Чего распознавание не делает

* **Сшивка дуг зависит от того, все ли гибы распознаны.** Механизм
  работает: на чистом исходнике прямые и скругления собираются в одну
  замкнутую полилинию с выпуклостью (проверяется `test_arcs.py`:
  габарит 300.0 x 150.1 мм при эталоне 300 x 150, четыре скругления
  ровно по 90°). Но если хоть один гиб на ксерокопии распознан
  частично, кольцо не замыкается, и дуги остаются отдельными ARC - как
  на поз.3, где из шести дуг четыре стыкуются с прямыми точно в ноль,
  а левый гиб распознан наполовину.
* **Радиусы, диаметры, дроби, буквенные обозначения.** OCR настроен на
  числа; R30, ⌀10, 6x50 как значения не разбираются.
* **Разрезы, штриховку, сварные швы, основную надпись.**

Это заготовка для доработки в CAD. Инструмент снимает ручной обмер и
обводку - самую нудную часть, - но проверять чертёж всё равно инженеру.


## Если установка библиотек не проходит

Приложение перебирает восемь способов установки и печатает, что делать
дальше. Самый частый случай на Windows - **«Missing dependencies for
SOCKS support»**: в системе задан прокси `socks5://` (обычно остаётся от
VPN-клиента), а модуль PySocks не установлен, и pip падает ещё до
обращения к сети.

Прокси может быть задан в трёх разных местах, поэтому перебираются все:

    переменные окружения      ->  попытки со снятием ALL_PROXY и прочих
    файл pip.ini              ->  попытки с ключом --isolated
    настройки Windows         ->  попытки с обходом через no_proxy=*

Обход через `no_proxy=*` работает так: Python игнорирует любой прокси при
этом значении, но только если в окружении вообще есть прокси, поэтому
подставляется заглушка `http://127.0.0.1:1`.

Если все восемь не сработали, разбирайтесь по порядку:

    1) поставить PySocks
       python -m pip install PySocks --proxy ""

    2) обойти прокси на время установки
       set NO_PROXY=*
       set HTTP_PROXY=http://127.0.0.1:1
       python -m pip install ezdxf pyyaml matplotlib ruamel.yaml opencv-python-headless numpy pillow pypdfium2 pytesseract

    3) убрать прокси из настроек самого pip
       python -m pip config list
       python -m pip config unset global.proxy

    4) отключить прокси в Windows: Параметры - Сеть и Интернет -
       Прокси-сервер, снять «Использовать прокси-сервер»

**Ошибка сертификата SSL.** Соединение режет антивирус или шлюз:

    python -m pip install ezdxf pyyaml --trusted-host pypi.org --trusted-host files.pythonhosted.org

**Сети нет вообще.** На машине с интернетом:

    pip download ezdxf pyyaml matplotlib ruamel.yaml opencv-python-headless numpy pillow pypdfium2 pytesseract -d wheels

перенесите папку `wheels` и здесь:

    python -m pip install --no-index --find-links wheels ezdxf pyyaml matplotlib ruamel.yaml opencv-python-headless numpy pillow pypdfium2 pytesseract

Запуск без попыток установки:

    python kmd_app.py --no-install
